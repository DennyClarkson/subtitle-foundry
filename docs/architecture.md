# 字幕工坊 implementation contract

`electron/paths.cjs` resolves the application root at runtime. Runtime downloads, Electron userData/sessionData/temp/logs and npm caches remain inside it. The user can select any writable workspace: media, presets, projects, outputs and workflow caches are stored there. Managed paths are checked against canonical boundaries, including directory junctions. No installers, global packages or shell-generated FFmpeg commands. Secrets stay in the main-process environment, never renderer/local storage/project/logs.

Electron main/preload mediate all filesystem and process access. The React frontend is under `src`, domain modules under `electron/core`. Cue times use seconds, start inclusive/end exclusive. `shared/types.ts` is the IPC contract; `defaults.cjs` contains initial values and `workflow.cjs` validates complete versioned presets.

Subtitles module exports parseSrt(text), serializeSrt(cues, field='text'), buildAss(cues, style), encodeSubtitle(text, encoding), normalizeCues(cues), alignTranslation(source,translated). FFmpeg module exports buildEncodeArgs({input,output,assPath,options,duration,preview}), validateEncode(options), parseProbe(json,path), encoder catalog/presets. Use shell:false, no raw shell arguments, and an ASS path relative to job cwd with safe ASCII filenames.

UI workflow: import video/sample or existing SRT; startTranscribe -> {cues,transcriptPath,folder}; startTranslate -> {cues}; edit cues; exportSubtitles -> one/two SRT and ASS; startBurn -> {path,url,folder}. Preview produces a short real FFmpeg clip. API supplied on window.studio. Completion broadcasts include full results once; history keeps only compact summaries (maximum 50 jobs). Projects retain editable cues and can be reopened. Cancellation terminates children/API requests and waits for cleanup.

`shared/timing.mjs` derives display timestamps without changing raw cues. ASR can attach a reliable last lexical token `speechEnd`. In order: trim to speechEnd plus tail padding, subtract manual end trim, apply optional maximum duration, then fill short positive gaps to the next cue. Existing overlaps remain. SRT, ASS and the renderer all use this helper, then apply the global offset once. Imported SRT has no lexical metadata and uses manual controls. Final cues are never lengthened by gap filling.

`electron/media.cjs` owns bounded media registrations and cancellable file streams. The renderer releases URLs on replacement/unmount. Request cancellation, eviction and app shutdown close associated streams. `storage.cjs` prunes only recognizable managed caches, protecting registered playback files and live encoder owners. Temporary audio, partial encodes and batch `.work` are removed when work settles; marked scratch from dead processes is recovered later. User source media and finished outputs are never cache-evicted.

Design: industrial/utilitarian dark editing workbench, left navigation, large video+cue editor center, right inspector; palette #151A1D #F3F0E8 #40C9A2 #E6AE5D. Fonts Bahnschrift, Microsoft YaHei UI, Consolas. Lucide icons, Tailwind available. Real working controls and actionable errors; no placeholder metrics or fake preview.
